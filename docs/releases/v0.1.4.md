Fifth test release of **Harness Designer**. It adds bought multi-conductor cables, so a twisted pair is cut and bought once, and it corrects and completes the standard parts.

## Bought multi-conductor cables

A twisted pair or multicore cable you buy (the type K pair of a thermocouple, a CAN pair) is now one cable in the harness: **WC1, WC2…**
- **Its conductors are still ordinary wires,** each with its own name, color and ends. They take the cable's wire type.
- **The BOM counts it once,** at the length of its longest conductor. Before, every conductor was counted, so a pair asked for twice the cable.
- **The cut list shows it in one row,** with its conductors underneath, in its connector's block as usual.
- **In the bundle it's one element** with the whole cable's diameter. Alone in a segment it isn't twisted with anything.

How to set it up:
- **Library → Wires:** the new **Conductors** column. More than 1 means a bought cable, and its OD is the whole cable's.
- **Inspector of a wire:** **Bought cable** → "+ New WCn" for the first conductor, then pick that WC for the others.
  - Changing the wire type of one conductor changes the whole cable.
  - A cable left with no conductors is removed.
  - Duplicating a connector gives the copy its own cable.
- **Wires tab:** a **Cable** column shows which WC each wire belongs to.
- **New check, "Bought cables":** a conductor with another wire type, or more conductors in use than the cable has.

## Standard parts

- **Bosch 1 928 404 669**, the harness connector of the Bosch LSU 4.9 lambda sensor, with its MCP 1.5K contacts (1241379-1 for 0.20–0.35 mm², 1241381-1 for 0.5–1.0 mm²).
- **VAG 1J0 973 733 is the LSU 4.2 connector,** not the LSU 4.9 one: its description is corrected.
- **The VAG coil and lambda connectors are female** on the harness side. The coil connector gets its Junior Power Timer 2.8 contacts.
- **Contacts added:**
  - **Superseal 1.5:** 282404-1 pin and 282403-1 socket, 22–20 AWG.
  - **Mini Timer connectors** ("MINI TYMER 02W-F", "ORIGINAL 03W_F"): Junior Power Timer 2.8 sealed, 929931-1 for 0.22–0.5 mm² and 929930-1 for 0.5–1.0 mm².
- **Each connector takes the right contact for each gauge on its own:** the first one fits the thinner wires, and the larger one is picked automatically for wires that don't fit it.

**Library → Add standard parts** adds what's new to an existing library. It never changes parts you already have, so correct those by hand if needed: the gender of the VAG connectors, the description of the 1J0 973 733.

## Updating from 0.1.3

- **Projects are upgraded to the new file format** the first time 0.1.4 opens them, with a `.v1.bak` copy next to each (`.v0.bak` for files from 0.1.2 or earlier). Libraries keep their format.
- **After the upgrade, 0.1.3 can no longer open those projects.** To go back, use the `.bak` copies.

## Install

Download `Harness Designer_0.1.4_x64-setup.exe` below and run it.
- It installs per user, over the previous version. It doesn't need administrator rights.
- **Windows SmartScreen may warn** because the installer isn't code-signed: click **More info → Run anyway**.
