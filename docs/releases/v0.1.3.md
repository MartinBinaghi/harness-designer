Fourth test release of **Harness Designer**. Most of the work is under the hood: safer files, faster calculations and one place for every workshop rule.

## Files

- **Versioned file format.** Projects and libraries record their format version.
  - A file from an older version is upgraded the first time it's opened or saved.
  - Before the upgrade, a copy is kept next to it as `<file>.v0.bak`.
  - A file from a newer version of the program is left untouched. The program says so instead of opening it.
- **Connector photos are stored apart** from the connector data. The library saves faster, and each photo is loaded only when it's shown.
- **The library saves only what changed.** If a save fails, the next one writes everything.
- **Undo back to the saved state** no longer marks the project as modified.

## Faster

- Costs, checks and "Ends at" are calculated once for each change and shared by every tab. Before, each tab did its own calculation. With the first real harness built in the program, this takes a few milliseconds.

## Fixes

- **Grounds don't join circuits anywhere.** Two wires to the same ring lug were already shown apart in "Ends at". Now they are also apart in the "same net, different names" check and in the diagram highlight.
- **A new wire from a pin** gets a wire type that fits a contact for that cavity. Contacts of the same size and gender are tried as well as the connector's own contact.

## Updating from 0.1.2

- **Your library and your projects are kept and upgraded** the first time 0.1.3 opens them, with a `.v0.bak` copy of each.
- **After the upgrade, 0.1.2 can no longer open them.** To go back, use the `.v0.bak` copies.

## Install

Download `Harness Designer_0.1.3_x64-setup.exe` below and run it.
- It installs per user, over the previous version. It doesn't need administrator rights.
- **Windows SmartScreen may warn** because the installer isn't code-signed: click **More info → Run anyway**.
