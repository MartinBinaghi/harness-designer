First test release of **Harness Designer**, a desktop application for designing motorsport wiring harnesses. It is meant for building the first real harnesses in the workshop and adjusting the program with that experience.

## What's in it

- **Harness model**: topology (nodes and segments with lengths), connectors or device connectors, splices, grounds, components, wires and twist groups.
- **Pinout editor** in Connectors: you load the harness connector by connector, and the wires are created from the pins.
- **Calculations**:
  - cut length with twist factor and margin (or a length set by hand);
  - bundle diameter;
  - suggested heat-shrink and its cut length;
  - boots and T-molds;
  - BOM with spare parts and costs.
- **Diagram** (free or to scale) and a pin-to-pin **schematic** generated from the data.
- **Connector faces drawn by the program**: Deutsch DT/DTM/DTP, TE Superseal 1.0/1.5 and MIL-DTL-38999.
- **Devices** (PDMs, ECUs…): the pinout can be pasted from the client's spreadsheet or PDF.
- **Checks**: gauge vs. contact range, missing contacts and sealing plugs, heat-shrink that doesn't fit, broken references…
- **Printing**: pinout sheets in the workshop format, cut list by connector, assembly drawing (A4/A3) and a label list (CSV).
- The parts library opens by itself and saves automatically. The project asks before closing if it has unsaved changes.

## Install

1. Download `Harness Designer_0.1.0_x64-setup.exe` below and run it.
   - It installs per user and doesn't need administrator rights.
   - Supported on Windows 10 and 11.
2. **Windows SmartScreen may show "Windows protected your PC"**, because the installer isn't code-signed yet. Click **More info → Run anyway**.
3. On first start the app copies a sample parts library to `%APPDATA%\com.martinbinaghi.arneses\library.db`. To see a complete example harness, use **Topology → Load sample**.

## Known limitations

- **Unverified library data**: the standard parts in the library (connectors, contacts, sealing plugs, heat-shrink) are marked *unverified* until they are checked against each datasheet. The library has no prices.
- **Unconfirmed cavity numbering**: some drawn connector faces use numbering inferred from the family. The app warns when that's the case.
- **Windows only**: Mac and Linux are not supported yet.
- **The concentric twisting module** (optional) is not implemented yet.
