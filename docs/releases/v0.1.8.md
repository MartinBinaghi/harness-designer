Ninth test release of **Harness Designer**: revisions you can freeze and compare, a Schematic made for checking circuits, pasting a connector's pinout, warnings for data that looks mistyped, and recovery of unsaved changes.

## Updating from 0.1.7

- **The program offers it by itself:** an **"Update to 0.1.8"** button appears in the status bar (or click the version to check).
- **Projects change format (6).** A harness opened or saved with 0.1.8 can't be opened by 0.1.7 afterwards; a copy of the original is kept next to it (`<file>.v4.bak` or `.v5.bak`). Update every computer where you use the same files. Libraries don't change format.

## Revisions

- **New "Revisions" tab.** **Freeze** keeps a full copy of the harness as it is now, inside the same file, with a name (A, B, 2…; the next one is suggested), date and notes. The harness's revision field takes that name. With unsaved changes, **"Save and freeze"** saves first.
- **Compare** any two states: the open harness (with what isn't saved yet), a frozen revision, or **another harness file** (it's only read, never changed, even if it's from an older version). You get what was added, removed or changed: harness data, connectors pin by pin (which wire arrives and where it goes), wires, splices, grounds and components, segments and breakouts, twist groups and bought cables. **"Compare with now"** does it against the open harness in one click.
- Each revision can be **exported** as a harness file of its own (**Export…**), to send it, or deleted.
- "Save as" takes the revisions along to the new file.

## Schematic

- **Filter the wires**: type an ID, name, label, colour or signal type ("5V", "W012", "red"), or click a signal type. Only those wires stay, with their pins and the blocks they touch, arranged compactly (if the main connector has none of them, the connector with the most goes on the left).
- **Your arrangement is saved with the harness**: blocks no longer move by themselves when the data changes. A new block goes where the automatic arrangement puts it. **"Re-arrange"** goes back to the automatic arrangement.
- **Focus**: choosing a connector, splice or ground highlights its wires and dims the rest; choosing a wire highlights its circuit.
- **Side of a block**: the button in each block's header chooses which side all its wires leave from (automatic → right → left). It's saved with the arrangement.
- **Legend** (bottom right): the colours of the wires on screen, with their signal types and how many there are; click one to filter by it.
- **Dragging a block over many wires no longer lags.**
- **New "Schematic" sheet in Print**, to check a circuit with the tester: the same drawing, filtered by signal type or text, with the legend below. Layout **"Compact (automatic)"** or **"As arranged in the Schematic tab"**. The whole harness on one sheet may not be readable: print it by circuit or on A3.

## Connectors

- **"Paste pinout…"** pastes a connector's table from Excel or a PDF, one row per pin.
  - Choose what each column is (Pin, Function, Category, Goes to, Wire type, Color, or ignore it). With a header row, the columns are recognized by themselves.
  - The preview says what each row will do.
  - Each row does the same as typing it by hand; an empty cell or "n/c" changes nothing.
  - Pins that already have a wire are left alone, unless you tick **"Replace what's already there"**.

## Checks

New warnings for data that looks like a typing mistake:
- **"Name looks mistyped"**: in the same circuit, a name equal to the others except for a number ("13V+ WG" among the "12V+ WG").
- **"Wires without a name"**.
- **"Missing signal type"**: only when one can be suggested (from wires with the same name, the rest of its circuit, or a signal type in its name).

## Recovering unsaved changes

- While the harness has unsaved changes, the program keeps a copy every 10 seconds. If it closes suddenly, the next time it opens it asks whether to **recover** them. The harness opens with the changes not saved yet, and undo goes back to what's in the file.

## Other

- Tabs with no harness open now show the file bar (New, Open, Save, Save as…, Load sample) instead of only a message.

## Install

On a computer without the program, download `Harness Designer_0.1.8_x64-setup.exe` below and run it.
- It installs per user and doesn't need administrator rights.
- **Windows SmartScreen may warn** because the installer isn't code-signed: click **More info → Run anyway**.
