Sixth test release of **Harness Designer**. From this version on, the program updates itself, and the installer brings the workshop's own parts library.

## Updates

- **The version is shown in the status bar**, bottom right: "Harness Designer 0.1.5". Click it to check for updates.
- **The program looks for a new version when it opens.** If there's one, an **"Update to …"** button appears in the status bar. Without internet, nothing happens and the program works as usual.
- **Updating doesn't uninstall anything and keeps your data.** The program asks first and saves pending library changes. It warns you if the project has unsaved changes, then closes, installs the new version and opens again.
- **Only versions signed by the workshop are installed.**

This version still has to be installed by hand, because 0.1.4 can't update itself. The first automatic update will be from 0.1.5 to the next one.

## Library

- **The installer brings the workshop's parts library** instead of an example one: what you get on a new computer.
- **The default library lives in `Documents\Harness Designer\library.db`.** If the program loses its settings (for example, after uninstalling with "Delete the application data"), it opens that one again instead of starting with a fresh copy. A library you chose with Open or Save as is still remembered.
- **New sample harness** ("Load sample" in Topology), made with the workshop's parts: an ECU, MAP, water temperature, a coil, an injector and an exhaust thermocouple with its bought twisted pair.

## Updating from 0.1.4

- **Install it over 0.1.4.** On the "already installed" page, keep **"Uninstall before installing"** and click Next. In the uninstaller of the old version, **don't tick "Delete the application data"**.
- Files keep their format: 0.1.4 projects open as they are.

## Install

Download `Harness Designer_0.1.5_x64-setup.exe` below and run it.
- It installs per user, over the previous version. It doesn't need administrator rights.
- **Windows SmartScreen may warn** because the installer isn't code-signed: click **More info → Run anyway**.
