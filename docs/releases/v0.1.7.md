Eighth test release of **Harness Designer**, with the changes asked for while building the TC2000 engine harness: better printed sheets, a cut list by connector pair, a faster Schematic, and a breakout boot that can hold several segments.

## Updating from 0.1.6

- **The program offers it by itself:** an **"Update to 0.1.7"** button appears in the status bar (or click the version to check).
- **Projects change format (4).** A harness saved with 0.1.7 can't be opened by 0.1.6 afterwards; a copy of the original is kept next to it (`<file>.v3.bak`). Update every computer where you use the same files. Libraries don't change format.
- **The ring terminal is now called "RING TERMINAL 16mm2 M6"** in the standard parts. In a library from 0.1.6, rename it by hand (Library → Connectors → its part number) before "Add standard parts", or it gets added twice.

## Harness

- **"Goes to" finds what you type anywhere in the destination**, by code or by name: "X3:r" or "motor:r" find "X3 · MOTOR:r" (the pin with the same upper/lower case first). Arrows and Enter or a click to choose; Esc goes back.
- **"↓ next" copies the row as it is** (function, category, wire type, colour and destination, unless the destination is a pin) to the next free pin. Change by hand what's different.
- **Straight boot on a breakout: several segments can leave by its small end.** Inspector of the node → **"Cable side (small end)"**, one box per segment. They're checked together against the boot's cable side, and its leg comes off the heat-shrink of each one.
- **Checks warns when no main connector is chosen** ("Main connector"): without it, the assembly sheets don't know where the harness starts or how far each point is.

## Printed sheets

- **Assembly drawing:**
  - In each breakout's sheet, outlets go left or right as in the diagram (backward = on the same side as the incoming segment).
  - Drawings use a fixed scale, so the lettering no longer gets huge with few elements.
  - **"Whole harness on one sheet"** is now the overview and every breakout's fan in one drawing. The "To scale" option is gone.
- **Pinout sheets:**
  - Connectors follow each other without blank pages or gaps; a connector that doesn't fit is split, and each continuation starts a new page.
  - Connectors with **25 ways or more** (ECU, engine, interconnect) get a page at the end with their front and rear views, large, with the wired pins highlighted.
  - Thin lines between rows in the Pin, Function and Ends at columns.
- **Cut list:**
  - **"Group by: Connector to connector"**: one block per pair of ends ("X1 · ECU A ↔ X3 · MOTOR"). A wire to a splice goes with the connector on the other side of the splice, and a loose wire at a connector's node goes with that connector.
  - **"Wire type and color"** order keeps each reel together.
  - **"Hide names (count identical wires)"**: wires with the same type, colour, length and twist go in one row with the quantity.

## Schematic

- **Faster** on big harnesses: clicking a wire, opening the tab and dragging a block.

## Install

On a computer without the program, download `Harness Designer_0.1.7_x64-setup.exe` below and run it.
- It installs per user and doesn't need administrator rights.
- **Windows SmartScreen may warn** because the installer isn't code-signed: click **More info → Run anyway**.
